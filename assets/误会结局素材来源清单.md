# 《荆棘之路》误会结局素材来源清单

两张剧情 CG 都以非 Q 版风格绘制。头像按原游戏和上一份隐藏结局包里的 Q 版胸像风格制作。瑞希差分以新版胸像为底，适配隐藏结局包内的 `assets/characters/mizuki/portrait.png`。真冬差分使用原游戏的头像。

| 文件 | 来源与处理 |
| --- | --- |
| `assets/scenes/rumor_hallway.png` | 基于[官方神山高校傍晚走廊原图 bg_a000502](https://storage.sekai.best/sekai-jp-assets/scenario/background/bg_a000502/bg_a000502.png)重新取景与绘制，沿用原游戏第一关的暖橙与淡紫配色，以及 `good_caught.png` 的非 Q 版 CG 画风。角色服装按原游戏头像及[神山制服游戏画面](https://yagami51530.hatenablog.com/entry/2023/10/08/220000)校对。修订版重新安排两位主角的身体朝向、重心和视线，把原创同学分到储物柜旁和走廊深处，并把真冬的腿部服饰修正为深色连裤袜。1920×1080 不透明 PNG。 |
| `assets/scenes/rumor_alone.png` | 在本包走廊 CG 的基础上生成后续画面，沿用同一[官方走廊底稿](https://storage.sekai.best/sekai-jp-assets/scenario/background/bg_a000502/bg_a000502.png)。压低夕照，移除围观者，真冬穿深色连裤袜独自伸手，瑞希只留远处背影。1920×1080 不透明 PNG。 |
| `assets/characters/classmate/portrait.png` | 以原游戏中的神山背景男学生为轮廓参考，自行生成原创黑发男同学胸像。制服对照[官方游戏里的神山男生制服画面](https://cdn-ak.f.st-hatena.com/images/fotolife/y/yagami51530/20231008/20231008080049.png)的蓝西装、浅色滚边、白衬衫与条纹领带。660×660 透明 PNG。 |
| `assets/characters/mizuki/portrait_panic.png` | 编辑上一份隐藏结局包的新版瑞希胸像，修改红晕、含泪的眼睛、波浪嘴和汗滴。沿用原图的外轮廓、服装和画布位置。660×660 透明 PNG。 |
| `assets/characters/mafuyu/portrait_puzzled.png` | 编辑原游戏真冬头像，以眉眼角度和不对称眼睑表现轻微的疑惑感，嘴仍是短直线。外轮廓、发型和衣服与基准图对齐。660×660 透明 PNG。 |
| `assets/audio/sfx/15_crowd_murmur.wav` | [Bexhill College Hallway Loop](https://freesound.org/people/pydsigner/sounds/580685/)，编辑者 pydsigner，原始录音为 [College Hallway ambience](https://freesound.org/people/Bexhillcollege/sounds/274213/)，作者 Bexhillcollege。另叠入 IENBA 的 [Small Crowd Walla](https://freesound.org/people/IENBA/sounds/653920/)。三者均为 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。截取 Freesound 公开高质量试听，削弱近处语音的清晰度，配上走廊底声并做淡入淡出。5.20 秒，44.1 kHz、16-bit 立体声 PCM WAV。 |
